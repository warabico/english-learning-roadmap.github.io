# 07 - Internationalization (i18n)

## 対応言語

| コード | 言語     | フォールバック |
|--------|----------|---------------|
| `en`   | English  | (基準言語)    |
| `ja`   | 日本語   | `en`          |

初期表示言語はブラウザのロケールから自動検出し、Settings で手動切替可能。

---

## ライブラリ

**i18next + react-i18next**

```bash
npm install i18next react-i18next
```

- `useTranslation()` フックで各コンポーネントから利用
- JSON ファイルによるリソース管理
- 言語切替はランタイムで即時反映（ページリロード不要）

---

## ファイル構成

```
src/i18n/
├── index.ts                   # i18next 初期化
└── locales/
    ├── en/
    │   └── translation.json   # English
    └── ja/
        └── translation.json   # 日本語
```

---

## 初期化 (`src/i18n/index.ts`)

```typescript
import i18n from "i18next";
import { initReactI18next } from "react-i18next";
import en from "./locales/en/translation.json";
import ja from "./locales/ja/translation.json";

i18n.use(initReactI18next).init({
    resources: { en: { translation: en }, ja: { translation: ja } },
    lng: navigator.language.startsWith("ja") ? "ja" : "en",
    fallbackLng: "en",
    interpolation: { escapeValue: false },
});

export default i18n;
```

## リソースキー設計

ネームスペースはフラットな1ファイルに統一し、ドット記法でセクションを区別する。

### キー命名規則

```
{screen}.{component}.{element}
```

例: `worldMap.categoryCard.verified`

## コンポーネントでの使用方法

```typescript
import { useTranslation } from "react-i18next";

function CategoryCard({ category }: { category: SkillCategory }) {
    const { t } = useTranslation();

    return (
        <div>
            <span>{t("worldMap.categoryCard.verified")}</span>
            <span>{t("worldMap.categoryCard.progress", { percent: 62 })}</span>
        </div>
    );
}
```

## 翻訳対象外の文字列

以下はロケールファイルに含めない:

- CEFR レベル表記 (`A1`, `B2` など) — 国際標準で翻訳不要
- ノード名・カテゴリ名 — 英語学習アプリのため英語表記固定
- クイズの問題文・選択肢 — `src/data/quizzes.ts` で管理（英語固定）

---

## 言語切替の永続化

選択言語は `elt_settings.uiLanguage` に保存され、次回起動時に自動復元される。

```typescript
// Settings画面での言語切替
const handleLanguageChange = (lang: "en" | "ja") => {
    i18n.changeLanguage(lang);
    updateSettings({ uiLanguage: lang });
};
```
